# Examples
Three input/output pairs showing the contract holding. Each input is shown as the translator reads it (numbered, with its trigger index). Each output passes `python3 verify/check.py`. These examples are separate from the test inputs in `inputs/`, so a run on those inputs is not answered by an example.
This file is generated by `tools/build_examples.py` from `verify/examples/`.

## ex1-plain
